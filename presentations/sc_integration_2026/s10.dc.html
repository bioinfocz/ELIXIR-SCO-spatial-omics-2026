First align the datasets: keep the directions both agree on

1. Run PCA on each dataset separately, using the shared genes.
2. Pair up the directions of the two PCAs that are most similar: these pairs are called principal vectors (method: PRECISE).
3. Keep only pairs that really agree (cosine similarity above 0.3), drop the rest as dataset-specific.
4. Project both datasets onto the kept directions, then search neighbours there.
Intuition: biology (cell types) should create the same main axes in both datasets. Axes seen in only one dataset are more likely technical.
Abdelaal et al., NAR 2020 (PCA per dataset, PRECISE, threshold 0.3); Mourragui et al., Bioinformatics 2019 (principal vectors). Animation: schematic.
