The methods

Three families of methods, one from each in the practical
Joint embedding
Put both datasets in one shared space, then copy from the nearest neighbours.
SpaGE, Seurat, LIGER, gimVI
Practical: SpaGE
Probabilistic mapping
Learn a table M: one row per reference cell, one column per location. Each row is a set of probabilities that sum to 1: where this cell most likely sits.
Tangram, novoSpaRc, SpaOTsc
Practical: Tangram

Probabilistic modelling
Assume the counts at a location = number of cells of each type × that type's average profile (signature), plus noise. Fit the numbers that explain the counts best.
cell2location, RCTD, stereoscope, CARD
Practical: cell2location
Families overlap in use: an embedding or a mapping can also impute genes and transfer labels; a model can be read as a map of cell types.
