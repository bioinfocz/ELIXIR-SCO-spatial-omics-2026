Step 1 · on the scRNA-seq reference
Estimate each cell type's signature gf,g: expected counts of gene g in type f, with a negative binomial regression that can remove batch effects.

Step 2 · on the spatial data (raw counts)
Explain the counts at each location s as a mixture of those signatures, and estimate the number of cells ws,f of each type.
Cell2location, needs a GPU in practice
countss,g ~ NB( μ )    μs,g = mg · Σf ws,f · gf,g + background
mg · gene-specific detection efficiency
ws,f · what we want: cells of type f at location s
gf,g · signatures from step 1, fixed
background · RNA outside any cell
You set a prior: the expected number of cells per location.
