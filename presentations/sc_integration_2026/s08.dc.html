Roadmap · same order as Practical 5

Three tools, three ways to use the reference

1
SpaGE
joint embedding
In: spatial and reference, both normalized
Out: predicted expression of unmeasured genes in each spatial cell
Check: hide a measured gene and predict it
2
Tangram
probabilistic mapping
In: the same two datasets, shared genes
Out: a cell-to-location map; from it, imputed genes and cell-type maps
Check: compare with SpaGE on the same genes
3
cell2location
probabilistic model
In: raw counts, reference cell types
Out: estimated number of cells of each type at each location
Check: compare with the MERFISH labels
In the practical, the slow steps (Tangram mapping, cell2location training) were run beforehand on a GPU; you load their results.
